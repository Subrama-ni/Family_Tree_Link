# 🌳 Family Tree Link

A Full Stack Family Relationship Management System built using **React.js, Spring Boot, and MySQL** that helps families digitally organize, visualize, and preserve family relationships, memories, and life events in one centralized platform.

---

## 🚀 Project Overview

Family Tree Link is designed to create a digital representation of family structures while providing tools to manage members, relationships, timelines, family galleries, and analytics.

The application allows users to build an interactive family tree, maintain family records, track important life events, store family memories, and export data for backup and sharing.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Subrama-ni/Family_Tree_Link.git
```

### Backend Setup

```bash
cd backend
```

Configure MySQL database settings in:

```plaintext
application.yml
```

Run Spring Boot application:

```bash
mvn spring-boot:run
```

### Frontend Setup

```bash
cd frontend/family-tree-frontend

npm install

npm run dev
```

Frontend runs on:

```plaintext
http://localhost:5173
```

Backend runs on:

```plaintext
http://localhost:8080
```
